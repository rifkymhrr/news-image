A self-contained newspaper front page covering six stories from the approved
17 November 2026 news brief: Shenzhen diplomacy, Hormuz shipping, Ukraine,
AI chip export rules, measles and digital outages. The summit is described as
scheduled for Thursday; the image does not claim it has already happened.

Run `python3 main.py` with Python 3.13. Standard library only. The program copies
the complete pre-rendered `entry.png` to `/output/entry.png` and publishes it
atomically. The bundled PNG is 1024 × 1024 pixels and 81,212 bytes. No fonts,
renderer, package installation, model or network call is needed during execution.

News facts come only from Muse's supplied `news_content.md`, kept in the private
build evidence. The compositor tightens its wording; it adds no news sources or
claims of independent fact verification. The full image text, source hash,
build-time renderer and two-run verification are packaged separately for review.
